# 🚀 Practice Agentic AI & LangChain Workspace

Welcome! This repository tracks my hands-on journey building production-grade LLM applications and Agentic workflows using **LangChain** across multiple state-of-the-art model providers.

## 🛠️ Tech Stack & Environment
- **Orchestration Framework:** LangChain (Modern LCEL & Message Architecture)
- **Model Providers Configured:** - **Google Gemini Engine:** (`gemini-2.5-flash`) via `langchain-google-genai`
  - **Groq LPU Inference Engine:** (`qwen/qwen3-32b`) via `langchain-groq`
- **Package Manager:** `uv` (Blazingly fast dependency management)
- **Environment:** Interactive Jupyter Notebooks isolated within a local `.venv`
